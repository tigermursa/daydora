# Daydora

**Live:** https://daydora.vercel.app/

A minimal date-remembering app — add birthdays, anniversaries, deadlines, or any important day and track how many days are left.

**Features:** Single-user login with 20-min sliding session · Home shows upcoming events sorted by nearest date, today's events highlighted on top · Full CRUD with toast notifications · Yearly recurrence for birthdays/anniversaries · Month-view calendar · Fully responsive dark-green UI.

**Stack:** Next.js 16 + React 19 + TypeScript + Tailwind v4 + MongoDB Atlas + Sonner · Deployed on Vercel.
